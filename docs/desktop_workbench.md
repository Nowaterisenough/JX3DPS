# 中文桌面战斗实验室

## 当前范围

桌面使用新运行时，支持太虚剑意与长歌莫问。配置、宏校验、补全、批量模拟、单次记录、断点调试及报告均按所选心法运行。旧 ScriptInterpreter 和演示数据不参与模拟。

本次界面迁移不代表旧引擎所有能力已迁移；与旧界面的差异见文末对照表。

## 布局与操作

桌面使用 Qt 6.12 Widgets，保留 Magpie 的视觉样式，导航在窗口顶部整体居中。主导航为模拟、循环宏、配置库、角色配置、模拟统计、时间轴、增益分析与设置，两侧留白等宽。“宏语法…”不占主导航，放在循环宏标题行右侧，点击打开独立窗口。角色配置的属性与收益、奇穴与秘籍、常驻增益，以及设置的常规、关于，在下方的面包屑行中横排切换；引擎状态、搜索与检查按钮也位于该行。所有入口均接入实际功能，不添加无实现的 Magpie 功能。

模拟页保留配置与循环宏并排；其他配置页使用独立内容区，其中属性页限制卡片组宽度，避免拉长属性与数值之间的距离。取消左侧导航占位，内容区使用完整窗口宽度。切换页面复用同一份控件、宏文档和模拟会话，不复制输入、不丢失撤销或断点。

- 模拟配置左侧使用两列紧凑面板，顶部为横排方案栏与开始按钮。方案的导入、导出、删除及重置收进“更多”菜单。
- 配置区上半部为模拟设置（心法及五项运行参数）和常驻增益，中部为属性、收益、流程宏三块并列区域，奇穴/秘籍独立放在最下方横排。原“目标…”入口及目标数值表单已移除，目标与初始状态直接写在流程宏中。不再使用“属性/加成/配装/收益”混合页签。属性保持游戏内单列：名称在左、数值在右，按身法/根骨、攻击力、命中、会心、会心效果、加速、破防、无双排列，后面补充破招、武器伤害。名称列最小 56px、数值列最小 88px 并使用其余宽度、列距 6px，为增益差值留出空间；数值组仍右对齐、字号与行高不变。
- 属性与右侧收益采用等宽卡片、左右各 12px 内边距、相同的十行定义和 19px 行高，逐行对齐；悬停任一侧时，同时轻亮对应的两行。28px 框外标题行位于页面底色上，下面间隔 4px 才是独立的圆角内容卡片。卡片组靠上摆放，高度不超过 270px，不随窗口高度拉出大块内留白。正文与标题字号保持不变。收益标题右侧标注“秒伤 / 提升”，左数值为所选比较增量带来的秒伤增量，右数值为同一增量的总提升比例；悬停可查看模式、实际增加点数和单位。未支持、固定命中等状态使用居中灰色标签，不混入百分比列，尚未计算的数值显示 `--`。底部操作区有细分隔线，左侧“同数值 / 同费用”分段切换，右侧“计算”为可持续选中的自动收益按钮；完整“同属性费用”定义保留在提示中。两者均为 26px 高，与左侧导入、编辑按钮对齐，不增加正文行。
- 属性卡片右上角“配装…”打开独立非模态窗口，主界面的属性、收益和奇穴仍保留。配装窗口复用同一组装备选择与特效控件，关闭再打开保留选择；模拟或调试期间可查看装备预览，影响模拟的特效输入继续锁定，不中断调试。主窗口关闭时一并关闭配装及相关辅助窗口。加成移到“编辑数值”窗口的“加成”页。
- 上排模拟设置与常驻增益使用独立横向布局，不再沿用中排属性/收益/流程宏的列宽。模拟设置整个分组固定为 224 个逻辑像素（默认配置栏中原为约 436px），常驻增益紧邻其右侧，间隔 4px；十二项常驻增益改为三列四行、图标在左文字在右，38px 图标与文字间隔 6px，原 11px 标签字号不变，利用释放出的宽度而不是留下空洞。两张卡片的上下边缘保持对齐。
- 中排流程宏固定为 224 像素，属性与收益仍等宽、逐行对应；底部奇穴/秘籍横跨整个配置区，九个槽位单行等距排列，图标和名称尺寸不变，默认模块高 100px。预览说明、旧规则和清空按钮移到页签同一行右侧，不再占卡片正文高度；模拟页配置栏初始宽度为 664 像素、最大 760 像素，属性页卡片组最大宽度为 664 像素，避免窗口放大时数值分散。属性、九重奇穴、常驻增益和默认模拟参数通过实际布局完整展示，而不是关闭滚动条后裁掉内容；长篇秘籍、装备说明与展开的旧规则仍可按需滚动。
- 心法选择使用旧版太虚剑意、莫问图标，位于模拟设置内部首行，右侧显示心法名称，不再与页签并排。点击图标打开单列竖向列表，每行直接显示图标和名称；支持键盘切换和配置保存，调试期间锁定选择。
- 模拟设置直接用单列表单显示模拟次数、工作线程、战斗时长、随机种子和输入延迟，不含 QScrollArea 或 QTabWidget，不靠隐藏滚动条裁掉内容。输入框上限 136 个逻辑像素，标签列距 6px、左右内边距 4px、上下内边距和行距 2px；字号、输入高度与参数范围不变。原生数值框按范围估算的最小宽度不再撑开卡片，最小窗口下五项参数完整可见。长随机种子仍完整保存和编辑，光标可在输入框内移动查看，悬停提示包含完整当前值，不缩小字体或截断数据。此紧凑宽度仅用于模拟页，独立属性编辑窗口和展开配置页不受影响。
- 战斗时长只编辑数值（支持原有小数精度），“秒”是输入框右侧固定显示的暗灰单位 `#92929d`，不是可编辑后缀。单位使用独立标签并预留文本区域，不进入输入内容、全选或复制，也不能被删除；清空输入、输入法组合或选择数值时仍显示。数字保留正常亮色，字号、字段尺寸、步进和按 1/16 秒对齐的规则不变，单位随禁用状态一起变暗。
- 流程宏提供“脚本 / 时间轴”视图切换，标题行“展开…”打开独立时间轴编辑器，“语法…”打开帮助。开场设置单目标和初始资源，战中可定时改变目标气血、距离。未支持的战中参数、多目标、切目标明确报错，不静默忽略。模拟和暂停调试期间只读，可查看和复制；编辑流程宏不会修改循环宏的文档或断点。
- 心法与常驻增益的选择框仍为居中的图标，不显示下拉箭头；popup 不再横向排列图标，而是 44px 行高的竖向列表，每行包含 32px 图标、名称和当前已选项的主题色对勾。“无”保留为可清空项，完整说明仍可悬停查看。宽度根据名称在 220–360px 间适配，最多展示八行，更多选项纵向滚动，不换列或产生横向滚动条。保持 180 毫秒 OutCubic 展开动画、屏幕边界避让、靠近底部时向上展开；展开中也支持上下键、Home/End、回车确认及 Esc 取消，关闭后立即停止动画。
- 心法、常驻增益、奇穴和弹出图标列表在绘制时裁去素材四周各 6.25% 的外圈，隐藏图像自带的边框。主面板的心法与常驻增益填入圆角内部并保留选中细框，不叠加对勾；popup 的对勾位于选中行右侧，不遮挡图标。奇穴填入圆形槽位并以亮色圆环表示已选。
- 奇穴选择参考 [魔盒奇穴模拟器](https://www.jx3box.com/macro/talent/) 当前公开版本 `v20260524`：每重显示一个圆形图标槽，名称位于下方。第 1 重为核心四选一，第 2–6 重各四选一，第 7–9 重共用十二个候选，选择三项且不可重复。常规候选纵向展开，混选候选以三列网格展开；已在其他混选槽选择的项目禁用。当前太虚、莫问各提供 36 个不同候选，名称、图标和描述从魔盒该版本完整加载。
- 九重奇穴目前用于配装预览，选择会随心法独立保存，并可导入导出。现有战斗引擎仍基于旧版迁移规则；新版奇穴效果尚未迁移，存在新版选择时拒绝启动模拟/调试，不能仅凭同名把新版效果映射到旧实现。清空新版配装后可使用“旧规则”中的原模拟选项，旧配置的奇穴标记完整保留。切换心法、隐藏奇穴页或开始模拟/调试时关闭候选弹窗。
- 切换到秘籍或展开旧规则时，底部模块临时展开到 270px，长内容仍可滚动；返回九重预览并收起旧规则后恢复 100px 单行布局。展开、收起只影响视图，不改变配装、流程宏或配置快照。
- 模拟结果移到循环宏下方的独立卡片，显示上次平均秒伤、完成情况及结果分析/时间轴/单次记录入口，为左侧配置腾出完整高度。其中“自动收益”与收益卡片的“计算”选中状态同步，不再点击即单独启动计算。调试时隐藏该结果卡片，空间交给运行状态。带收益的模拟完成后直接更新属性右侧的独立收益模块。
- 右列为循环宏。新建、打开、保存、检查留在编辑区；查找、替换、另存为、补全和语法帮助在“更多”菜单，也保留快捷键。编译错误就近在编辑器下方显示。
- 循环宏框外标题行右侧的“宏语法…”与属性区“配装…”采用相同的文字按钮入口；模拟页和循环宏页均可打开同一个非模态帮助窗口，不切换页面、不打断模拟或暂停调试，不修改宏文档、撤销记录、断点或配置。关闭再打开保留阅读位置，切换心法时更新对应技能与增益说明。更多菜单及关于页复用同一窗口，主窗口关闭时一并关闭帮助。
- 结果分析：点击模拟结果面板的“技能统计”，或使用顶部导航进入工作台内的分析页；不再弹出独立统计窗口。顶部“模拟统计”默认打开历史概览，技能统计按钮仍直达技能表。模拟历史、基准比较、完整属性收益及导出均保留，也可从“时间轴”进入单次记录。宏与配置详情默认折叠，点击同名按钮展开。
- 图表采用 Magpie 的标题分隔、大号指标、珊瑚色细线与淡渐变、绿色虚线基准及光晕标记、灰色状态胶囊。每个点对应一次已完成运行，不填充演示数据或将折线插值成额外战斗采样。鼠标悬停显示真实数值，点击或左右键切换联动历史记录；设置基准后虚线使用该结果，否则使用首轮。取消记录不画入曲线，选中取消记录时标注“最近完成”。零秒伤与单点数据也有明确显示。技能占比加入细进度条，时间轴背景、边框、游标和提示色统一到相同主题。
- 循环宏调试：宏顶部的“断点调试”开关显示 VS Code 风格的浮动工具条，拖动手柄可在宏区域调整位置。运行状态、执行轨迹、玩家与目标、断点位于编辑器下方的页签，可拖动分隔条调整高度。运行状态展示下一阶段、上一执行结果、增益层数与剩余时间、技能冷却与充能；莫问另有曲目、影子计时与增益快照。
- 底部常驻单行状态，右侧显示紧凑进度与取消，完整结果说明可悬停查看或进入结果分析。

普通模拟、属性收益完成后留在主界面更新输出，不自动切走配置。单次记录打开时间轴。调试使用循环宏原有文档，保留撤销和断点；查看结果分析时隐藏浮动工具条，返回循环宏后恢复暂停位置，正在调试时输入仍保持锁定。关闭“断点调试”开关会停止会话并恢复输入。

默认窗口为 1206 × 860 个 Qt 逻辑像素，顶部导航高 52，标题栏高 30，内容区水平留白 18，配置区初始宽度为 664。为容纳新增的底部奇穴行、保持文字与图标大小，最小窗口调整为 1120 × 820，主导航、两心法默认属性与九重奇穴均完整可见，不需拖动滚动条。窗口低于 900 高时，模拟页收起重复的引导说明、压缩面包屑行与留白，不缩小内容文字和奇穴图标。宏文件信息与调试位置合并为一行，浮动工具条默认位于编辑器右上角。

界面、诊断、帮助、命中结果和配置项使用中文。宏指令、可用英文别名、快捷键、品牌名及 JSON 字段标识保留原写法。Qt 标准菜单、对话框按钮加载随 Windows 包部署的中文翻译。

视觉样式集中在 `controls/theme/workbench_theme.h`，外壳、线性图标与开关位于 `magpie_shell.h`。从参考 PNG 取样得到背景 `#1A1A1E`、卡片 `#232327`、边框 `#333339`、分段底座 `#2D2D33`、子项选中态 `#27272C`、滚动条 `#56565F`、状态绿 `#6FD99B`。移除旧版蓝色/金色面板与按钮渐变，采用 12–14px 卡片圆角、1px 分隔线、14px 常规 UI 字体。游戏图标与宏语法色保留功能语义。尺寸以 Qt 逻辑像素定义，截图比较需结合系统 DPI；字体栅格化与原生窗口边缘仍受平台影响。

强调色不再固定为淡紫色，而是从当前心法选择器实际显示的图标提取。`controls/theme/accent_color.h` 按图标显示时相同的 6.25% 裁边取样，过滤透明像素、低饱和灰白高光和暗部，以加权色相直方图寻找主要色簇，再保留其色相调整饱和度与亮度，保证深色背景上的辨识度和主按钮文字对比度；缺图或没有有效彩色像素时使用中性灰，不虚构门派配色。悬停色与按下色由同一主色生成。

启动时按已保存心法取色，切换心法时同步更新开始模拟/调试、循环宏运行按钮、选中图标边框、键盘焦点、进度条、技能占比条和时间轴选区。调色板和样式按工作台窗口保存，不修改全局应用配色；独立配装窗口、编辑窗口及图标/奇穴弹窗沿父窗口使用同一强调色，多开不同心法的工作台互不串色。页面结构、字号、深色中性背景、图表的珊瑚色趋势/绿色基准、宏语法色以及属性增减的红绿色保持原语义。

分组标题参考 Magpie 的框外分区标签：模拟设置、常驻增益、循环宏及其他有标题的 QGroupBox，在边框上方预留 28px 标题空间，标题不压边框，也不占卡片内部。无标题的方案栏和结果卡片不留空标题行。属性与收益使用独立的标题控件和内容控件，实现相同的外置结构。

属性、收益、流程宏并排时统一为 270px 高，上下边缘对齐；底部奇穴/秘籍独立成行，不再与属性卡片横向争空间。所有框外标题行与页签统一为 28px 高，下方到内容卡片的间距同为 4px。收益模式切换与“计算”选中按钮仍为 26px 高，属性与收益各行保持对应。

模拟设置、常驻增益与循环宏使用同一组标题间距参数：QGroupBox 的顶部预留为 28px 标题行加 4px 间隔，共 32px。流程宏语法入口、常驻增益分段切换和宏语法入口位于边框外侧，间距与属性、收益和奇穴模块一致；同一行的模拟设置卡片顶边同步对齐。带标题行操作的分组复用 `controls/theme/header_group_box.h`，缩放时保持操作入口靠右。模拟设置移除内部页签和滚动容器，为最小窗口中完整展示五项参数留出空间，不缩小控件或字号。

导航与页签的交互核对了本机 Magpie 0.1.1559 及其公开 [app.css](https://github.com/yetone/magpie/blob/main/internal/gui/assets/app.css)、[app.js](https://github.com/yetone/magpie/blob/main/internal/gui/assets/app.js)：滑块 280ms，文字过渡 180ms，按压 140ms、缩放至 0.96，共用 `cubic-bezier(.2,.8,.2,1)`。悬停只调整文字，不再额外绘制一块背景；左键松开在原按钮内才切换，拖出取消。顶栏使用单个共享滑块，页内控件使用 2px 内缩、5px 圆角及细阴影。点击鼠标不留下蓝色焦点框，键盘导航仍有焦点提示。快速切换从当前动画位置接续，布局变化与隐藏后显示直接对齐。

### 游戏属性与收益对应

属性排版依据用户确认的真实游戏截图，来自 [JX3BOX 文章 65071](https://www.jx3box.com/bps/65071) 的 [属性截图](https://cdn.jx3box.com/upload/post/2023/8/16/226494_2366160.png)，不使用魔盒配装器导出图的多列布局。[同文的装备截图](https://cdn.jx3box.com/upload/post/2023/8/16/226494_2141217.png) 用于区分游戏装备提示与配装导出图。

主面板显示当前输入按模拟器旧规则折算的静态数值（含所选常驻属性，不含战斗临时效果），不是把截图示例值写死。点击“编辑数值”可编辑原来的基础攻击、心法攻击、会心等级等分项；“导入魔盒属性”仍直接可用。主属性未导入时显示 `--`，不由攻击反推；现有运行时只判定命中/会心，命中固定显示 100% 并说明限制。该界面调整不改变底层战斗规则。

`game_attributes.h` 统一属性名称、顺序和收益键。独立收益模块与详细收益表按同一十行顺序显示，即使后端返回顺序不同也按键对应。主属性收益显示“暂未支持”、命中收益显示“固定命中”，没有用零值充当计算结果。其余八项收益按所选模式传入实际增量，单位是等级/基础数值而非增加 1% 面板属性。

“同数值”每项分别增加 100 点。“同属性费用”比较相同属性预算，而不是相同的属性点数或相同的面板百分比。概念参考 [JX3BOX 装备属性与装备分数的计算](https://www.jx3box.com/bps/56964)；实际预算样本采用 [魔盒模拟建模文章 71692](https://www.jx3box.com/bps/71692) 所链接的 [120 级模拟器常量](https://github.com/IcyTide/Simulator/blob/3a9d31157a76fa2461ff7dc42a2389a7dfd97f41/base/constant.py)，与本项目固定的 120 级旧规则对应，不混用缘起或当前新版数值，也不将该样本宣称为游戏内 1 装分。

| 属性 | 同数值增量 | 同属性费用参考增量 |
| --- | ---: | ---: |
| 外功基础攻击（太虚） | 100 | 398 |
| 内功基础攻击（莫问） | 100 | 475 |
| 会心、会效、破防、无双、破招、加速等级 | 100 | 883 |
| 武器伤害 | 100 | 597 |

同费用预算对应参考主属性 198 点，但本引擎尚不计算主属性单独收益，因此该行仍提示未支持。参考参数集中于 `attribute_gain_mode.h`。两种模式均真实计算：会心和加速按各自增量重跑循环，其余六项使用对应增量重新结算伤害统计，不将“加 100 点”的收益线性放大当作同费用结果，保留加速跨档等非线性变化。

“计算”是自动收益选项，默认不选中，并记住选择；点击只改变选中状态，不立即启动任务。选中后从开始模拟、循环宏运行按钮或 F5 启动的普通批量模拟会一并计算启动时选定模式的收益；未选中只执行基准模拟。断点调试与单次记录不附带收益计算，也不改变选中偏好。运行期间自动收益按钮禁用，完成或取消后恢复；进度包含基准与三组重跑，不把额外计算隐藏起来。两种模式分别保留本次输入的结果，未算过的模式显示 `--`，选中“计算”后重新开始模拟即可获得。切换比较方式不修改战斗配置、不清掉另一模式的有效结果；计算中切换模式不会被完成的旧模式结果强行切回。修改宏或配置后两份收益同时失效，历史结果仍保留；计算期间修改宏时，完成的旧结果仅进入历史，不回填为当前输入的收益。详细结果及导出报告继续保存实际模式、增量和是否请求收益。

选中按钮样式依据 Magpie [app.css](https://github.com/yetone/magpie/blob/main/internal/gui/assets/app.css) 的 `.text.ci-auto.on` 与 [app.js](https://github.com/yetone/magpie/blob/main/internal/gui/assets/app.js) 的自动签到开关：6px 圆角，普通态中性文字，选中态为主题色文字与 16% 主题色浅底，保留 `.96` 按压缩放与颜色过渡。对应 Qt `setCheckable(true)`，不是瞬时按压态或独立复选框；强调色沿用当前心法图标提取色。

设置页提供真实可用的设置搜索、记住窗口尺寸、恢复宏草稿、运行状态栏和编辑器字号，使用 QSettings 持久化。即使隐藏状态栏，正在模拟或调试时仍显示进度与取消入口。关于页显示实际 Qt 运行库版本、心法与规则限制、宏帮助和可复制的配置存储位置。

### 宏编辑

宏文件为 UTF-8，使用 QSaveFile 原子保存。退出时保存草稿、文件路径、修改标记、断点、配置与窗口尺寸；太虚与莫问的宏草稿分别保存，切换心法不丢失草稿。

Ctrl+Space 补全指令、条件、当前心法技能及增益；支持中文输入法、名称中部替换和单次撤销。运行时描述表是名称与别名的来源，不会推荐只能结算伤害的内部技能作为施放目标。检查宏与行内诊断使用同一个运行时编译器。

`buff:玄门` 与 `buff:玄门>0` 等价。莫问目标持续伤害可写 `tbuff:商`、`tbuff:角`。`bufftime`、`tbufftime`、`skill_cd` 在宏中以秒表示，调试操作数以帧显示，每秒 16 帧。

Ctrl+F 查找，Ctrl+H 替换，F3 / Shift+F3 下一处 / 上一处。支持大小写、完整名称匹配、循环查找、一次撤销全部替换。调试时仍可查找，替换和编辑被锁定。

### 断点调试

1. 选择心法及参数，编辑宏，点击宏行号设断点。
2. 在循环宏顶部开启“断点调试”。浮动工具条的播放按钮开始运行到断点；方案栏的“开始调试”初始化后停在第一条宏前。
3. F5 继续至断点或结束，F6 暂停，F10 执行一行，F11 执行一个条件或动作。
4. Shift+F11 执行本轮宏，Shift+F5 停止，Ctrl+Shift+F5 重新调试；浮动工具条提供相同操作。运行时显示暂停按钮，完成后禁用单步并允许重新运行。
5. “调试轨迹”显示实际条件值、短路跳转、施放成功或首个阻塞原因；点击定位宏行。

断点绑定编辑器文本块，插入或删除前面的代码时会随代码移动。会话期间锁定心法、配置和宏源代码。调试以分段执行保持界面可响应，不会在 GUI 线程无限运行。轨迹最多保留最近 2048 步，支持筛选及导出，避免长期调试无限占用内存。

莫问 `/fcast`、`/sfcast` 在进入宏行时先打断引导，再判定本行条件。因此条件为假也可能已打断；轨迹单独显示“引导打断”，不会误报为施放受阻。长清、修期在参考旧实现中无效果，选项提示中明确标记。

### 流程宏与时间轴编辑

流程宏的无时间前缀或零时间节点设置每场初始状态，非零时间节点改变战中的目标状态；循环宏负责技能选择。桌面端一次编译出经过校验的初始配置和事件序列；批量、单次记录、调试和收益各分支共享同一配置，不在每场战斗内重复解析文本，也不调用旧 ScriptInterpreter。

```text
/set_target level=124
/set_target shield=30000
/set_target life=100%
/set_target distance=4
/set_target vulnerable=0%
/set_player qidian=10
/set_player shadows=0
/set_player style=高山流水
00:30 /set_target life=50%
00:45.0625 /set_target distance=3
```

- `/set_target` 支持等级 110–130、防御 0–10000000、气血 1%–100%、距离 0–1000、易伤 0%–976.5625%。气血、距离最多两位小数，易伤最多四位小数；等级和防御为整数。
- `life` 和 `vulnerable` 建议带百分号，不带百分号时按比例解释，`life=0.5` 与 `life=50%` 等价。可写 `id=1`，其他目标编号不受支持。
- `/set_player` 支持太虚初始气点 `qidian=0..10`、莫问初始影子 `shadows=0..6`，以及 `style=阳春白雪/高山流水`（也可用 0/1）。每个心法只使用对应的资源配置；太虚沿用现有旧规则的开场 +1 气点（上限 10），不改变原数值表单的计算语义。
- 一行可写多个 `参数=值`，等号两侧不加空格。同一行重复参数会报错；分行重新赋值则按顺序覆盖。省略的参数使用默认值，而不是沿用上一次编辑的值。空脚本也使用默认目标和初始状态。
- 支持 `#`、`//` 注释。时间前缀为 `分:秒`，最多四位秒小数，必须对齐 1/16 秒（例如 `00:00.0625`）；不对齐的脚本文本报错，节点表单和拖动自动吸附到帧。最多 256 个节点，时间不超过 24 小时。
- 战中只允许 `/set_target life=... distance=...`，等级、防御、易伤和角色初始资源固定于 0 秒。节点按时间排序，同一帧按源码顺序覆盖，在技能和持续伤害定时器之前执行。战斗区间为 `[0, 时长)`，结束帧及更晚的事件保留但不执行，时间轴以灰色斜线区域和节点提示标出。
- 距离改变沿用技能现有的判距规则，不自动取消已经开始的运功、引导或持续伤害。气血是供条件和现有规则读取的设定比例，不由伤害扣减。当前仍不支持 `/wait`、`/stop`、`/add_target`、`/change_target` 或流程中的 `/cast`；未支持内容、未知参数、范围和精度错误都会阻止启动并定位到对应行。

主卡片时间轴显示开场、气血、距离三条紧凑轨道；展开后按八项参数分别显示轨道，并附时间顺序节点表。双击空白添加节点、双击节点编辑、拖动节点调整时间；选中后左右键逐帧移动，Shift+左右键每次一秒，Delete 删除，Ctrl+Z / Ctrl+Y 撤销和重做。滚轮缩放、拖动空白或 Shift+滚轮平移，“适应”显示全部事件。包含开场专属参数的整条节点不能拖到战中，应另建气血/距离节点。

脚本是唯一数据源，视图切换不修改配置。时间轴操作只改动对应源码行，保留其他行、注释以及移动节点时的原参数格式，每次操作可一步撤销。节点弹窗取消不写入，脚本在弹窗打开期间发生变动则拒绝覆盖并要求重新选择节点；无效脚本禁用可视化写入，但仍可撤销。运行或暂停调试时同步锁定两种视图并关闭未提交弹窗。

输入错误时保留上一次有效的数值投影用于界面显示，但绝不以旧配置偷偷启动模拟。错误草稿可以随工作台设置保留，重新打开后仍提示修正；导出和加载正式配置必须完整通过脚本及数值一致性校验，失败不部分修改配置。历史快照和报告保留原脚本文本及其编译后的目标/初始资源值。

### 配置与魔盒导入

配置导出使用 `jx3dps.desktop.config` 版本 4，包含心法、完整模拟值集合、两心法的九重配装和奇穴数据版本，以及带时间节点的 `flowMacro` 原始文本。没有流程宏字段的旧配置，按原目标/初始状态数值自动生成等价脚本；新配置必须保证脚本的开场投影与这些数值一致，战中事件不回写初始值。导入兼容同格式版本 2、3 与旧 `jx3dps.tai-xu.config` 版本 1，旧配置增加空的新版配装，保留旧规则标记。字段类型、范围、精度、枚举、秘籍组合、奇穴版本、候选归属及混选重复均先完整校验，再更新控件。错误不会留下半导入状态。随机种子用字符串存储，完整保留 64 位无符号范围。

命名方案支持保存、加载、删除和 JSON 导入导出。删除已有方案需确认。模拟历史中的“恢复宏与配置”恢复运行开始时捕获的输入，不读取之后已被编辑的内容。

“属性”页的“导入魔盒属性”接受旧版使用的属性对象：

- 太虚读取 `PhysicsAttackPowerBase`、`PhysicsCriticalStrike`、`PhysicsCriticalDamagePower`、`PhysicsOvercome`、`Agility`。
- 莫问读取 `LunarAttackPowerBase`、`LunarCriticalStrike`、`LunarCriticalDamagePower`、`LunarOvercome`、`Spirit`。
- 共同读取 `Strength`、`SurplusValue`、`Strain`、`Haste`、`MeleeWeaponDamage`、`MeleeWeaponDamageRand`。

按旧版整数顺序计算主属性攻击与平均武器伤害。输入会心等级已包含主属性贡献，不重复叠加；“已含主属性”记录其基数，用于食品药品增量的整数取整。导入会清除常驻增益选择和额外属性百分比，避免重复叠加，保留宏、奇穴、秘籍、装备特效和运行参数。原始装备清单或外部配装网站链接不是此入口的输入格式。

属性卡片的“配装…”打开独立窗口，太虚保留魔盒装备、套装及资料面板，莫问保留已有装备特效配置。该窗口按需打开，关闭后再次打开会保留本次选择；查看配装不会中断宏调试，调试期间特效输入锁定。选择候选装备目前用于配装预览，尚未自动汇总成新运行时的属性配置。

`data/jx3box` 的当前快照和 2026 年 4 月历史归档保持独立。数据资料合入不等于新运行时已经采用这些版本的战斗机制；新运行时的规则基准仍以两心法迁移文档为准。

### 常驻增益

`apps/desktop/data/permanents.json` 提取自 `ba960f7` 的两心法配置，并编译进应用资源，运行不依赖旧 worktree。

标题右侧使用“计入面板 / 基础面板”双选分段切换，高度 28px，与收益模式复用相同滑块和按压动画。默认选择“计入面板”，作为界面偏好保存，并兼容此前开关保存的选择。计入时属性显示增益后的总数值，前面以绿色 `(+增量)`、红色 `(-减量)` 标注相对基础面板的净变化，格式为 `(+增量) 总值`，保证各行末尾的总数值右对齐；没有变化的行不显示括号。百分比属性的括号表示百分点变化，并与主数值使用相同显示精度，不是相对增长率。主属性未记录时总数值仍显示 `--`，前面的括号只显示已知的常驻主属性增量，不反推总属性。

选择“基础面板”只隐藏常驻增益对面板的影响，所选增益仍参与模拟，收益仍按实际战斗配置计算；切换不改变配置快照、不清除两种收益缓存。分段切换在模拟/调试期间仍可操作，但增益选择控件继续锁定。基准面板通过清空配置副本中的常驻选择后调用同一属性计算流程得到，保留手动加成，并正确计算主属性换算、百分比加成和整数取整，而不是直接把食品描述的数值相加。

提供阵法、增强/辅助食品、增强/辅助药品、家园炊事、家园酿造、武器磨石和独立宴席选项。静态属性在 Prepare 前一次计算；身法/根骨增加时分别按旧版心法系数及基础会心系数取整，不在每次模拟事件中遍历配置 JSON。

阵法选择应用旧配置的 `AttributeAdditional` 常驻数值；动态游刃、精妙在心法配置中单独选择。阵法描述中提及但未迁移的团队交互不会被自动模拟。

### 模拟与结果

批量模拟在工作线程运行，进度每 250 毫秒刷新。取消在单场结束时生效，部分结果只统计已完成的场次；关闭窗口会等待正在执行的工作线程退出。普通模拟不收集整批逐事件记录。

普通模拟完成后即可查看技能统计，按伤害从高到低排列，展示事件数、总伤害、伤害占比、平均秒伤、平均单次伤害及命中、会心、识破、未命中次数。事件数和伤害为已完成战斗的合计，技能秒伤除以已完成场次及单场时长；DOT 每跳算一次事件。属性收益运行只收集基准战斗的技能统计。切换模拟历史时同步切换技能表，取消后的部分结果也可查看。

单次记录与调试都使用所选种子的第 0 场，使用相同的种子派生算法，可逐事件比较。事件页、时间轴和增益分析使用真实运行记录，技能统计在调试中持续更新。增益覆盖率和时间加权层数按已观察的模拟时长计算，永久增益在状态检查中显示“常驻”。

模拟历史保留本次会话最近 50 次结果，显示均值、总体标准差、最小/最大秒伤、运行耗时及校验值。可设基准、对比修改项、恢复输入及导出完整报告。基准比较为观察值对比，不是统计显著性检验。

启用自动收益时，按同数值或同属性费用模式对八项属性分别应用对应增量，展示秒伤变化及提升比例，详细表另列原始每点收益。会心和加速各重新运行循环。基础攻击、会效、破防、无双、破招、武器伤害使用基准战斗统计重算，保留 DOT 快照与实时属性以及莫问额外会效。所有分支使用相同宏、种子和模拟次数，实际执行基准及两组重跑，进度总数是请求次数的三倍。重跑分支可能改变事件顺序和随机数消耗，收益包含模拟波动。取消时保留已完整计算的项目；基准完成后，六项重算结果即可保留。未启用自动收益的普通批量模拟不增加额外战斗。

报告使用 `jx3dps.desktop.run` 版本 2，包含心法配置、宏、基准统计和属性收益数据；新增可选字段 `skillsCollected` 及 `skills`，保存每个技能的标识、名称、伤害和命中计数，整数总量使用字符串保留精度。机器字段采用固定英文名称。表格导出采用 UTF-8。

## 性能边界

桌面入口通过 `variant<太虚配置, 莫问配置>` 选择一次具体 Rules。普通批量实例仍为 `Simulation<Rules, false>`；单次记录和调试分别实例化 `Simulation<TracedRules<Rules>, false/true>`。普通批量热循环没有历史记录存储、记录回调、心法虚调用或 Qt 调试信息。

技能、增益名称转换和中文诊断在桌面边界处理；Prepare 的共享只读缓存及每工作线程复用的模拟器保持不变。莫问的记录容量预留为每帧 16 条伤害、40 条状态变化，再加固定余量。调试增益、伤害与宏步骤的界面投影独立于普通批量结果。

逐技能汇总复用每场结束时的伤害结算，通过 `TotalDamage` 的观察回调写入每线程的固定技能数组，整批结束后合并。不增加模拟次数，不保存整批日志，也不在每次命中时创建 Qt 对象或加锁。

## 图标与时间点属性

食品、药品、阵法、家园、磨石、宴席在主面板保持紧凑图标格，奇穴采用按重数排列的圆形槽位。常驻增益和奇穴的选中边框使用心法主题色，说明保留在中文悬停提示中。心法与常驻增益的 popup 采用图标加名称的竖向列表，选择“无”可清空；支持原有键盘选择、配置保存、导入和心法切换。奇穴候选和装备资料的专用弹窗不随此次下拉列表调整改变布局。旧规则图标目录 `apps/desktop/data/icons.json` 来自 `ba960f7/config/config.json`，派生技能沿用来源技能或奇穴图标。新版九重配置位于 `apps/desktop/data/talents.json`，来源为 `https://data.jx3box.com/talent/std/v20260524.json`，于 2026-10-02 核对魔盒版本索引；补充其缺少的 37 张游戏图标并编入应用资源，运行时无需联网加载。

时间轴技能和增益轨道使用真实图标；轨道左侧不再占用整列名称，悬停显示归属、名称、层数与生效区间。竖直游标在空白区域、技能与增益轨道均跟随鼠标，并与缩放和平移后的时间坐标一致。事件时间保留每帧 62.5 毫秒的精度。

右侧面板显示所指逻辑帧的通用属性、气点或曲目/影子、运功/引导、增益层数、技能冷却和充能。移出时间轴后保留最后一次查看的状态，方便继续查看面板图标。完整记录取该帧最后一次状态；调试当前帧只包含已经执行的操作，未执行到的未来时间明确提示“此时间尚未模拟”。修改配置不会回写已经记录的属性。

状态查询使用已有变更日志和每 256 条变更一个的检查点，随机回看至多重放 255 条变更。通用属性从规则实际使用的属性组合记录，只在数值变化时追加；莫问额外会效、腰部附魔随机强度等私有状态也包含在内，不根据增益层数猜测。技能专属加成和持续伤害/影子保留的旧快照不代表当时人物面板，故不混入通用属性。记录数据以增量方式从调试器传给界面，普通百万次批量不生成这些数据。
