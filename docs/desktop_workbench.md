# 中文桌面战斗实验室

## 当前范围

桌面使用新运行时，支持太虚剑意与长歌莫问。配置、宏校验、补全、批量模拟、单次记录、断点调试及报告均按所选心法运行。旧 ScriptInterpreter 和演示数据不参与模拟。

本次界面迁移不代表旧引擎所有能力已迁移；与旧界面的差异见文末对照表。

## 布局与操作

按旧版 `app/MainWidget.cpp` 的设置、属性、配置、输出、收益、常驻增益和右侧宏分区组织主界面。顶层仅保留“模拟配置”“结果分析”“宏调试”三个页面。

- 模拟配置左列：设置（心法、模拟参数、目标与初始状态）及开始模拟按钮；下方是属性、额外加成与配装特效。
- 模拟配置中列：配置方案、上次模拟平均秒伤及统计/时间轴/单次记录入口、属性收益。方案的导入、导出、删除及重置收进“更多”菜单。
- 常驻增益独立成列；该列下半部放置奇穴图标和秘籍页签，切换心法时直接显示该心法选项。
- 右列为循环宏。新建、打开、保存、检查留在编辑区；查找、替换、另存为、补全和语法帮助在“更多”菜单，也保留快捷键。编译错误就近在编辑器下方显示。
- 结果分析：完整空间展示模拟统计、时间轴、伤害事件和增益分析；模拟历史、基准比较、完整属性收益及导出均保留。
- 宏调试：上方为调试操作，左上宏、左下执行轨迹，右侧运行状态/玩家与目标/断点。运行状态展示下一阶段、上一执行结果、增益层数与剩余时间、技能冷却与充能；莫问另有曲目、影子计时与增益快照。
- 底部常驻单行状态；运行时显示进度与取消，完整结果说明可悬停查看或进入统计页。

普通模拟、属性收益完成后留在主界面更新输出，不自动切走配置。单次记录打开时间轴。主界面和调试页共用同一个宏文档，切页保留撤销、断点与暂停位置；查看配置或统计不会停止调试，正在调试时输入仍保持锁定。

默认窗口为 1400 × 900。较小窗口通过配置区滚动访问底部选项，宏编辑区保持独立；各个长表单也可单独滚动。配置区高度按最小布局需求计算，避免自动换行的输出标签将整个页面撑长。

界面、诊断、帮助、命中结果和配置项使用中文。宏指令、可用英文别名、快捷键、品牌名及 JSON 字段标识保留原写法。Qt 标准菜单、对话框按钮加载随 Windows 包部署的中文翻译。

### 宏编辑

宏文件为 UTF-8，使用 QSaveFile 原子保存。退出时保存草稿、文件路径、修改标记、断点、配置与窗口尺寸；太虚与莫问的宏草稿分别保存，切换心法不丢失草稿。

Ctrl+Space 补全指令、条件、当前心法技能及增益；支持中文输入法、名称中部替换和单次撤销。运行时描述表是名称与别名的来源，不会推荐只能结算伤害的内部技能作为施放目标。检查宏与行内诊断使用同一个运行时编译器。

`buff:玄门` 与 `buff:玄门>0` 等价。莫问目标持续伤害可写 `tbuff:商`、`tbuff:角`。`bufftime`、`tbufftime`、`skill_cd` 在宏中以秒表示，调试操作数以帧显示，每秒 16 帧。

Ctrl+F 查找，Ctrl+H 替换，F3 / Shift+F3 下一处 / 上一处。支持大小写、完整名称匹配、循环查找、一次撤销全部替换。调试时仍可查找，替换和编辑被锁定。

### 断点调试

1. 选择心法及参数，编辑宏，点击宏行号设断点。
2. 点击设置区“断点调试”或切到“宏调试”页，再点击“开始调试”；初始化后停在第一条宏前。
3. F5 继续至断点或结束，F6 暂停，F10 执行一行，F11 执行一个条件或动作。
4. Shift+F11 执行本轮宏，Shift+F5 停止；固定工具栏同时提供这些操作及重新调试。
5. “调试轨迹”显示实际条件值、短路跳转、施放成功或首个阻塞原因；点击定位宏行。

断点绑定编辑器文本块，插入或删除前面的代码时会随代码移动。会话期间锁定心法、配置和宏源代码。调试以分段执行保持界面可响应，不会在 GUI 线程无限运行。轨迹最多保留最近 2048 步，支持筛选及导出，避免长期调试无限占用内存。

莫问 `/fcast`、`/sfcast` 在进入宏行时先打断引导，再判定本行条件。因此条件为假也可能已打断；轨迹单独显示“引导打断”，不会误报为施放受阻。长清、修期在参考旧实现中无效果，选项提示中明确标记。

### 配置与魔盒导入

配置导出使用 `jx3dps.desktop.config` 版本 2，包含心法和完整值集合。导入兼容旧 `jx3dps.tai-xu.config` 版本 1。所有字段类型、范围、精度、枚举及秘籍组合先完整校验，再更新控件。错误不会留下半导入状态。随机种子用字符串存储，完整保留 64 位无符号范围。

命名方案支持保存、加载、删除和 JSON 导入导出。删除已有方案需确认。模拟历史中的“恢复宏与配置”恢复运行开始时捕获的输入，不读取之后已被编辑的内容。

“属性”页的“导入魔盒属性”接受旧版使用的属性对象：

- 太虚读取 `PhysicsAttackPowerBase`、`PhysicsCriticalStrike`、`PhysicsCriticalDamagePower`、`PhysicsOvercome`、`Agility`。
- 莫问读取 `LunarAttackPowerBase`、`LunarCriticalStrike`、`LunarCriticalDamagePower`、`LunarOvercome`、`Spirit`。
- 共同读取 `Strength`、`SurplusValue`、`Strain`、`Haste`、`MeleeWeaponDamage`、`MeleeWeaponDamageRand`。

按旧版整数顺序计算主属性攻击与平均武器伤害。输入会心等级已包含主属性贡献，不重复叠加；“已含主属性”记录其基数，用于食品药品增量的整数取整。导入会清除常驻增益选择和额外属性百分比，避免重复叠加，保留宏、奇穴、秘籍、装备特效和运行参数。原始装备清单或外部配装网站链接不是此入口的输入格式。

主目录合入新工作台后，右上角“太虚配装”保留魔盒装备、套装、技能、奇穴和秘籍图标面板。该窗口按需打开，关闭后再次打开会保留本次选择，查看配装不会中断宏调试或修改模拟输入。选择候选装备目前用于配装预览，尚未自动汇总成新运行时的属性配置。

`data/jx3box` 的当前快照和 2026 年 4 月历史归档保持独立。数据资料合入不等于新运行时已经采用这些版本的战斗机制；新运行时的规则基准仍以两心法迁移文档为准。

### 常驻增益

`apps/desktop/data/permanents.json` 提取自 `ba960f7` 的两心法配置，并编译进应用资源，运行不依赖旧 worktree。

提供阵法、增强/辅助食品、增强/辅助药品、家园炊事、家园酿造、武器磨石和独立宴席选项。静态属性在 Prepare 前一次计算；身法/根骨增加时分别按旧版心法系数及基础会心系数取整，不在每次模拟事件中遍历配置 JSON。

阵法选择应用旧配置的 `AttributeAdditional` 常驻数值；动态游刃、精妙在心法配置中单独选择。阵法描述中提及但未迁移的团队交互不会被自动模拟。

### 模拟与结果

批量模拟在工作线程运行，进度每 250 毫秒刷新。取消在单场结束时生效，部分结果只统计已完成的场次；关闭窗口会等待正在执行的工作线程退出。普通模拟不收集整批逐事件记录。

单次记录与调试都使用所选种子的第 0 场，使用相同的种子派生算法，可逐事件比较。事件页、时间轴、技能统计和增益分析使用真实运行记录。增益覆盖率和时间加权层数按已观察的模拟时长计算，永久增益在状态检查中显示“常驻”。

模拟历史保留本次会话最近 50 次结果，显示均值、总体标准差、最小/最大秒伤、运行耗时及校验值。可设基准、对比修改项、恢复输入及导出完整报告。基准比较为观察值对比，不是统计显著性检验。

“属性收益”单独运行基准及 8 个属性分支：基础攻击、会心、会效、破防、无双、破招、加速、武器伤害各增加 100 点；所有分支复用同一宏、种子和模拟次数，展示秒伤变化、每点收益及提升比例。会心和加速可能改变事件顺序和随机数消耗，收益包含模拟波动。取消时保留完整完成的属性分支。普通批量模拟不会为收益分析增加额外战斗。

报告使用 `jx3dps.desktop.run` 版本 2，包含心法配置、宏、基准统计和属性收益数据；机器字段采用固定英文名称。表格导出采用 UTF-8。

## 性能边界

桌面入口通过 `variant<太虚配置, 莫问配置>` 选择一次具体 Rules。普通批量实例仍为 `Simulation<Rules, false>`；单次记录和调试分别实例化 `Simulation<TracedRules<Rules>, false/true>`。普通批量热循环没有历史记录存储、记录回调、心法虚调用或 Qt 调试信息。

技能、增益名称转换和中文诊断在桌面边界处理；Prepare 的共享只读缓存及每工作线程复用的模拟器保持不变。莫问的记录容量预留为每帧 16 条伤害、40 条状态变化，再加固定余量。调试增益、伤害与宏步骤的界面投影独立于普通批量结果。

## 图标与时间点属性

食品、药品、阵法、家园、磨石、宴席和奇穴采用紧凑图标格。图像沿用旧版 `resources/images/JX3/Icons`，名称与说明保留在中文悬停提示中，金色边框和勾表示已选择。常驻增益点击打开图标选择列表，选择“无”可清空；支持原有键盘选择、配置保存、导入和心法切换。图标目录 `apps/desktop/data/icons.json` 来自 `ba960f7/config/config.json`，派生技能沿用其来源技能或奇穴图标。旧版没有专用映射的修期、大附魔和水特效使用旧版通用效果图标，提示中说明来源。

时间轴技能和增益轨道使用真实图标；轨道左侧不再占用整列名称，悬停显示归属、名称、层数与生效区间。竖直游标在空白区域、技能与增益轨道均跟随鼠标，并与缩放和平移后的时间坐标一致。事件时间保留每帧 62.5 毫秒的精度。

右侧面板显示所指逻辑帧的通用属性、气点或曲目/影子、运功/引导、增益层数、技能冷却和充能。移出时间轴后保留最后一次查看的状态，方便继续查看面板图标。完整记录取该帧最后一次状态；调试当前帧只包含已经执行的操作，未执行到的未来时间明确提示“此时间尚未模拟”。修改配置不会回写已经记录的属性。

状态查询使用已有变更日志和每 256 条变更一个的检查点，随机回看至多重放 255 条变更。通用属性从规则实际使用的属性组合记录，只在数值变化时追加；莫问额外会效、腰部附魔随机强度等私有状态也包含在内，不根据增益层数猜测。技能专属加成和持续伤害/影子保留的旧快照不代表当时人物面板，故不混入通用属性。记录数据以增量方式从调试器传给界面，普通百万次批量不生成这些数据。

## 旧界面对照与剩余差异

| 旧版功能 | 当前桌面状态 |
| --- | --- |
| 心法、次数、延迟、属性、目标 | 已接入太虚与莫问；输入延迟使用固定帧数 |
| 奇穴、秘籍、装备特效 | 展示新运行时已迁移项；莫问含橙武、水特效及三部位大附魔 |
| 配置方案、魔盒属性导入 | 已接入；新增严格校验和版本兼容 |
| 食品、药品、家园、磨石、宴席、阵法常驻属性 | 已接入旧数据；动态团队效果以心法配置已支持项为准 |
| 属性收益 | 已接入 8 项；主属性单独收益尚未提供 |
| 统计、技能占比、时间轴 | 已接入真实记录、历史、基准比较及增益分析 |
| 宏断点、单步、状态、原因分析 | 已提供固定调试操作栏、断点列表及调试轨迹 |
| 多个具名宏组及“宏·返回”跳转 | 尚未迁移，当前为一个线性宏程序；不应直接粘贴旧宏组并期待兼容 |
| 运行期事件脚本、多目标、移动/切目标 | 尚未迁移；当前配置单目标初始状态与结束时长 |
| 随机延迟区间、旧逻辑帧精度选择 | 尚未提供；新引擎按事件期限推进，输入延迟为固定帧 |
| 整批逐技能统计及逐场秒伤分布图 | 批量当前保留汇总量；逐技能统计来自单次记录或调试，分布图尚未迁移 |
| 可视化事件编辑、JCL 导入、关于 | 参考旧版按钮本身禁用；当前未添加这些无实现入口 |

因此不能将当前版本称为旧桌面的全部功能已完全对齐。剩余宏组、事件场景和多目标能力需要先扩展新运行时，再接入界面与调试器。

## 验证

桌面 Qt 集成测试覆盖太虚原流程、莫问断点与强制引导打断、同种子调试/单次记录逐事件一致、心法切换及重启草稿恢复、中文诊断与补全、魔盒导入原子性、旧配置迁移、常驻属性精确增量、属性收益与直接批量模拟校验值一致。

布局回归另外覆盖主界面输出/收益与详细统计一致、调试中跨页浏览保留暂停位置与输入锁定、跨页查找宏、共享文档的撤销与断点保留。截图检查包含 1366 × 900 和 1280 × 800 的主界面、两心法配置及独立调试页。

Windows 本机（在主项目目录执行）：

```powershell
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
$env:QT_QPA_PLATFORM_PLUGIN_PATH = 'C:\msys64\ucrt64\share\qt6\plugins\platforms'
cmake -S . -B build -DBUILD_APP=ON -DBUILD_TESTS=ON -DBUILD_PERFORMANCE=OFF -DJX3DPS_DESKTOP_TESTS=ON
cmake --build build --target JX3DPSDesktop desktop_tests test_jx3dps -j 4
ctest --test-dir build --output-on-failure -R '^(desktop_tests$|JX3DPS\.)'
```

设置 `JX3DPS_TEST_SCREENSHOT` 为以 `.png` 结尾的绝对路径，可在测试中导出配置、结果、宏搜索/补全、增益、调试轨迹、莫问断点及配装界面截图。主目录生成程序为 `build/bin/JX3DPS Desktop.exe`。

## Windows 运行目录

MinGW / MSYS2 构建在 Qt 部署后扫描可执行文件及插件的依赖，复制编译器运行库和 Qt 依赖的第三方 DLL，排除 Windows 系统库。中文 Qt 翻译同时部署。分发时复制整个 `build/bin` 目录及 `data/jx3box` 快照，不能只复制主程序。

合并后主目录桌面测试通过全部 32 项用例，覆盖旧版图标资源、图标选择/清空、连续时间游标、历史状态检查点、太虚与莫问属性记录、配装预览与暂停调试的共存，以及原有界面回归。桌面程序已在 PATH 只包含 Windows 系统目录、清除 Qt 插件环境路径后验证启动。离屏测试额外使用工具链中的 Qt6Test 和 qoffscreen 插件，正式程序使用随包部署的 qwindows 插件。
