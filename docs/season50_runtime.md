# 苍生铸世 50 级单目标运行规则

50 级运行时包含 20 个旗舰心法，可通过 `schools` 查询各自的可施放动作、九个默认奇穴和推荐秘籍。太虚剑意和莫问与其他心法共用主工作台。心法支持的招式、奇穴、秘籍、装备选项和默认宏可以从同一个内核查询。DOT、宠物攻击、神兵追击和招式子段由相应事件触发。

## 新增心法

在 `src/class/` 新建 `心法名.cpp`，包含 `common/builder.hpp`，在 `JX3DPS::runtime::season50` 命名空间定义与文件同名的 `Book 心法名()`。用 `Builder` 填入稳定代号、门派与面板换算、默认宏、奇穴、秘籍及技能，最后返回 `b.finish()`。CMake 会在下次构建时发现文件；桌面、CLI 和 Web 共用同一份心法目录。

技能伤害、增益和施放条件可直接组合通用操作。需要按当前帧读取状态并结算多个效果时，在该心法文件内编写 `EffectContext` 回调。可分别参考[天罗的重弩齐射](../src/class/天罗诡道.cpp)和[无方的中和](../src/class/无方.cpp)。

每个成功施放的动作触发一次 `pre_cast`。本体或各引导段按原定帧执行，收尾时触发 `post_cast`。普通引导被打断后取消余下段数；标记为蓄力释放的动作在已经打出至少一段时执行释放收尾。每次直伤或 DOT 结算走 `pre_damage` 和 `post_damage`。直伤取命中时的属性；DOT 使用挂上时保存的快照，并在每跳读取该效果要求实时结算的属性。

## 使用

- Qt 工作台：在主工作台「模拟设置」原有的心法下拉框选择心法。所有旗舰心法位于同一层。在下方九重奇穴、秘籍标签和配装面板配置效果，然后用右侧宏开始模拟。结果逐项列出名称、次数、会心次数和总伤害。
- Web：在心法下拉列表选择任一旗舰心法。展开「已实现的招式与配置」可选择已接入的奇穴、秘籍和装备。宏可用于批跑或单步调试。
- 原生命令行：`season50_runtime --list` 输出支持清单。`season50_runtime gfj --seconds 60 --iterations 100 --seed 42` 运行默认宏。`--macro 文件` 读取 UTF-8 宏，`--config 文件` 读取 JSON 配置。`--trace` 运行一场，输出逐击伤害、会心、层数和资源变化。同帧内用 `sequence` 区分先后。
- C ABI：`{"op":"schools"}` 返回 50 级规则清单。`start/next`、`debug` 及原生多线程 `batch` 共用心法代号。调试会话结束后请求 `{"op":"debug","action":"trace"}` 可取本场记录。

例如将以下内容保存为 `wf.json`，运行 `season50_runtime wf --seconds 10 --config wf.json --trace`。可以在记录中检查「使用橙武 → 川乌射罔」的引导是否完成，以及鉴魄证身实际发生的帧。

```json
{
  "attributes": {"attack_base": 10000, "crit": 2000, "haste": 0},
  "target": {"level": 54, "shield": 6592},
  "talents": ["相使"],
  "equipment": ["鉴魄证身"]
}
```

`tx`、`mw` 分别选择 50 级太虚剑意与莫问。默认载入该心法的宏、整数面板和已实现的奇穴、秘籍预设。传入空数组可清除对应选项，太虚和分山默认使用对应配装已验证的战中装备效果，其余心法默认关闭。魔盒宏原帖、面板数值、循环时长和当前整场偏差见[20 心法默认方案与在线对照](season50_presets.md)。属性是已折算的战斗属性，单位为游戏属性点；当前目标默认 54 级、6592 防御。目标时间线沿用现有协议，距离为百分之一尺，血量为万分比。宏可用心法资源名称，如 `[锐意>=60]`、`[温寒<=-1]`；按资源顺序也可使用已有的 `qidian`、`energy`、`rage`。

桌面配置按心法代号保存。加载 120 级历史方案时迁移运行参数和战中目标移动，50 级面板与奇穴按本赛季重新配置。各心法的宏草稿与断点使用独立存储。配装候选使用 2026-11-20 的旗舰 PvE 装备资料，按门派和主属性筛选；配装预览与手动面板分开保存。[装备资料版本](https://github.com/IcyTide/Generator/tree/7c1b07fd0e424cf92562c5d62199ed8e3c468027/assets/json) · [九重奇穴版本](https://data.jx3box.com/talent/std/v20261030.json)

## 战斗如何执行

已接入的数值秘籍按「技能·效果」选择，例如 `四象轮回·2%会心`。同一技能各条秘籍共享四本上限。部分秘籍改变攻击系数，有些只改变会心率或通用增伤。单个伤害事件只加载它所依赖的秘籍，同名百分比不会跨技能生效。

- 宏由项目的 `MacroCompiler` 编译。每场由 `Simulation` 重置资源、随机流及事件队列，按帧调度。调息、公共调息、读条、引导、串行充能、自然回能与延迟伤害各有自己的状态。引导中断会取消尚未产生的后续段和完成效果。
- 每一击单独抽取会心和基础浮动。需要概率触发的追击使用本场随机流，并以独立伤害事件登记。结算不会导入对方的 JCL、木桩循环、覆盖率、期望会心次数或期望追击次数。
- DOT 保存施加时的伤害属性，独立记录剩余跳数、下一跳和到期帧。破防、目标防御和易伤在实际生效时读取。引爆、提前结算指定跳数与重新施加是三种不同操作。同帧最后一跳先于状态移除。
- 伤害记录使用原项目的 `DamageIntent`，常规运行、分线程批跑、属性收益及调试都消费同一条时间线。50 级配置使用本赛季等级换算和内外功系数。[心法源文件](../src/class)

**技能攻击系数。** 20 个心法的技能本体、伤害子段、宠物和 DOT 共用第四版的攻击系数算法。当前技能表以整数保存每一档 `channel`。只有当季计算器的表达式可用时，先按该档完整表达式求值并截为整数；这些数值的来源仍是当季资料。改变系数的秘籍、套装、气劲或资源条件每次作用后写回整数。替换档位时取该档自己的系数，DOT 用挂上时的系数快照。[第四版原实现](https://github.com/Nowaterisenough/JX3DPS/blob/18691d95db1c4bafe86fc160b379ab4f433ea657/src/Damage/Damage.hpp#L29) · [共用公式](../src/core/runtime/attack_coefficient.hpp)

第四版直伤入口的额外准备帧传 0，AP 倍率为 `max(channel, 16) / C / 16`。DOT 用基础跳数 `N` 和基础间隔 `I` 求 `T = max(16, floor(N × I / 12))`，每跳 AP 倍率为 `channel × T / N / C / 16 / 16`。两者都按第四版的顺序用双精度除法，乘面板攻击后截为整数，再与武伤、固定伤害相加。50 级 `C` 为外功 89.92、内功 97.04。装备等固定真实伤害走独立的等级减伤与易伤结算。[当季常数来源](https://github.com/jx3dps-online/jx3dps-online-public/blob/54d8ccdb7528ba2b305a31f77c5710152d37bd9b/src/数据/常量/index.ts#L18) · [50 级逐击入口](../src/class/common/damage.hpp)

## 能按帧核对的机制

| 心法 | 核对点 |
|---|---|
| 太虚剑意 | 无我无剑先按半格气点选档，再消耗气点。命中叠一层叠刃，实际会心时额外叠一层。11 月后的非侠增伤为 686/1024。 |
| 莫问 | 「商」「角」各自挂 DOT；「羽」各提前结算最多两跳并扣掉相应剩余跳数。羽有三层串行充能。「使用橙武」给三次神兵窗口，神兵·羽按独立伤害事件计算。 |
| 分山劲 | 偃守孤旌期间斩刀使用战绝窗口，初始三层，每三秒回怒并掉一层，增伤按新版约 18%、12%、6% 结算。 |
| 孤锋诀 | 「威声」的 32 帧不切单刀窗口和 192 帧、限两次的额外 15 个百分点会心独立计时。界破是延迟伤害。 |
| 无方 | 橙武效果由一次真实施放打开。川乌引导按帧入列，神兵窗口在施放时锁定，每个实际命中跳均追加商陆与鉴魄证身（系数 1276）。提前打断只保留已命中的段。 |
| 太玄经 | 连极阵按 32 帧间隔检查碰撞、目标距离及星运，选择知微才会给目标施加 DOT。目标离开后返回可以改变实际命中的次数。 |
| 幽罗引 | 勾线起手读取心络，实际扣 20、30 或 40 点，分四、七或十次引导，逐段选系数并叠缠绞，谐调在完整引导结束时才产生。 |
| 花间、毒经、天罗 | 玉石分别吞噬三种 DOT 的剩余跳数；灵蛇存续期间每四秒普通攻击、每十二秒幻击；连弩与重弩根据每次射击时的鬼斧弹药选择伤害并扣弹。 |
